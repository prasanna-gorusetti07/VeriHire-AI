# VeriHire AI
### Evidence-Based Fake Job & Internship Offer Detection and Verification System Using AI Agents

VeriHire AI is an AI-powered verification platform designed to identify potentially fraudulent job offers and internship opportunities through evidence-based investigation and autonomous AI agents.

It helps users assess suspicious recruitment offers by analyzing company identity, website domains, suspicious payment requests, and other available evidence.

## 🎯 Problem Statement

Fake job offers and fraudulent internship opportunities are increasing. Job seekers may lose money and personal information because they cannot easily verify whether a recruiter or company is genuine.

VeriHire AI aims to make recruitment verification more transparent, evidence-based, and accessible.

## 💡 Our Solution

VeriHire AI uses AI agents and evidence-based analysis to investigate recruitment offers, identify suspicious indicators, calculate risk scores, and provide users with verification results.

## ✨ Key Features

- **AI Agent-Based Investigation:** Uses an agent-driven workflow to analyze recruitment information.
- **Evidence-Based Verification:** Evaluates available evidence instead of relying only on assumptions.
- **Company Identity Verification:** Checks company identity and possible brand impersonation.
- **Domain Analysis:** Examines website and email domain indicators.
- **Fraud Risk Scoring:** Combines detection rules and AI analysis to estimate risk.
- **Privacy Protection:** Supports personally identifiable information (PII) masking.
- **Investigation History:** Keeps track of previous verification cases.
- **Dashboard:** Provides an overview of verification activity and risk results.

## ⚙️ Technology Stack

- Next.js
- React
- TypeScript
- Supabase
- AI Agent-Based Workflows
- Evidence-Based Risk Analysis

## 🔄 How It Works

1. User submits a job offer or internship details.
2. The system analyzes the submitted information.
3. Available company, domain, and recruitment evidence is examined.
4. AI agents assist with investigation and analysis.
5. Risk indicators and scores are calculated.
6. The system presents a verification result with recommendations.

## 🛡️ Privacy and Security

- PII masking before AI processing where enabled.
- Evidence-oriented analysis.
- Secure handling of sensitive information.
- Users should avoid sharing unnecessary personal information.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/prasanna-gorusetti07/VeriHire-AI.git
   ```

2. Open the project folder:

   ```bash
   cd VeriHire-AI
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables in your local `.env` file. Never upload API keys or secrets to GitHub.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open:

   ```text
   http://localhost:3000
   ```
